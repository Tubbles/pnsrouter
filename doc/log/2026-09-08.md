# 2026-09-08

## Toolchain: plain podman, no host Rust

Tags: #toolchain #process

- Nothing is installed on the host. All builds and tests run in a podman container built from `dev/Containerfile`, which derives from LibrePCB's CI image `librepcb/librepcb-dev:ubuntu-24.04-4` and adds clippy and rustfmt (the image installs Rust 1.92 with the minimal profile). `dev/in-container.sh` is the single entry point.
- Reason: the user does not work interactively on this machine, so editor integration and a newer stable toolchain on the host buy nothing, and a container that matches LibrePCB's CI keeps the MSRV honest. Distrobox was considered and rejected because its convenience (display, DBus and GPU passthrough for GUI programs) is only needed for manual GUI testing, which will happen on the user's laptop instead.
- Rust on the host stays possible later without changing anything in the repository, since the scripts only wrap cargo.
